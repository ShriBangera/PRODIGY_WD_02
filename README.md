# Stopwatch - A mini project for Prodigy Infotech

Stopwatch is a simple web application that allows users to measure elapsed time with start, stop, and reset functionalities.
It is built using HTML, CSS, and JavaScript.

## Project Overview

### This project features:

* A digital stopwatch display
* Start, Stop, and Reset buttons

## Technologies Used

* Frontend: HTML5, CSS3

* Scripting: JavaScript

* Styling: CSS

## How to Run

1. Clone or download the repository:

    git clone https://github.com/ShriBangera/Stopwatch.git


2. Open index.html in a web browser.

3. Use the Start, Stop, and Reset buttons to control the stopwatch.
